1. Introduction                                            *note-introduction*

This plugin adds syntax highlighting, folding, and a handful of editing
commands for `.note` files: plain-text notes built out of nestable,
titled blocks.

The `note` filetype is set automatically for any `*.note` file.

==============================================================================
2. The note format                                                *note-format*

A block is a titled region delimited by a matching bracket pair followed
by a colon and an opening brace, closed by `}`: >

    [a bracket-titled block]: {
      content goes here
    }

    <an angle-titled block>: {
      content goes here
    }

    (a paren-titled block): {
      content goes here
    }
<
Blocks may nest freely.

Inline emphasis markers wrap their contents in a repeated delimiter, e.g.
`*bold*`, `~strikethrough~`, `` `code` ``, `$highlight$`, `#alert#`,
`!warning!`, `^flag^`, and `%percent%`. See |note-syntax| for the full
list and examples/syntax-examples.note for a exhaustive demonstration of
every construct.

==============================================================================
3. Mappings                                                      *note-mappings*

All mappings below are buffer-local to `.note` files and are defined via
|<Plug>| mappings, so they can be remapped without editing the plugin: >

    nmap <buffer> <your-key> <Plug>(note-create-block)
<
Default mappings (skipped automatically if you map the `<Plug>` target
yourself first):

    <leader>[  (n, i)  *note-create-block*
        Wrap the current line in a new block, or insert an empty block
        below the cursor if the line is blank.

    vib        (n)     *note-select-block*
        Visually select the block enclosing the cursor.

    za         (n)      *note-squish*
        Fold every block in the buffer. Also run once automatically when
        a `.note` buffer is first read, unless |g:note_auto_squish| is 0.

    zoa        (n)      *note-unsquish*
        Open every fold in the buffer.

==============================================================================
4. Configuration                                            *note-configuration*

                                                          *g:note_squish_pattern*
g:note_squish_pattern~
    Vim regex used to find block headers when folding. Defaults to: >

        '^\s*\[.*\]:.*\s{'
<
                                                            *g:note_auto_squish*
g:note_auto_squish~
    When non-zero (the default), fold every block automatically the
    first time a `.note` buffer is read.

==============================================================================
5. Syntax groups                                                  *note-syntax*

    noteTitle          ## Title
    noteListItem        - item / * item / + item
    noteTodo           TODO
    noteBlock          [title]: { ... } / <title>: { ... } / (title): { ... }
    noteStars/noteStar  *bold*
    noteTildes/noteTilde ~strikethrough~
    noteBacktick        `code`
    noteDollars/$       $highlight$
    notePound           #alert#
    noteExclamation     !warning!
    noteCarrot          ^flag^
    notePercents/%      %percent% (conceals to a single glyph)
    noteLineTilde       ~~~
    noteLineDashed      ---
    noteLineEquals      ===
    noteLineStars       ***
    noteCodeBlock       ``` fenced code ```
    noteComment         /** block comment **/
    noteCommentLine     // line comment
    noteUrl / noteLink  http(s):// and file:/// links
    noteArrow           --> and <--

See examples/syntax-examples.note for a working example of each group.
